# Hosted vault workspace

Mode: Operate / Read.

Scope: `harness\web\index.html`, `harness\web\tasks.css`,
`harness\web\tasks.js`, `harness\web\dashboard.js`.

One configured personal owner checks focus and existing task attention, then
opens a canonical daily finding or weekly digest. Original evidence is visible
in one interaction and its same-origin source in two. Feedback is not approval;
Make a task uses capture, exact preview, explicit approval and publication receipt.

The owner explicitly rejects the incumbent green/beige ledger. Use a distinctive
AI-first workspace: deep-ink dark and cool light themes, electric indigo/violet
with coral AI highlights, elevated surfaces, system typography, fluid motion and
reduced-motion support. No external assets. Today leads with focus and source-
grounded next steps. Flow pairs a stage board/list with task detail and copilot.
Preserve Knowledge, Areas & projects, Activity and all publication/closure states.
Phone controls include a prominent microphone and accessible task chat.

Task outcome and done condition lead the detail. A Capture / Detail / Estimate /
Plan / Execute / Resolve / Learn rail prepares source-bound AI work; chat accepts
English and Russian text/voice instructions. Applied changes show diffs and
receipt-bound Undo; approvals remain explicit wherever required by the server.
Never infer verified completion from a model reply. All conversation state is
in memory and cleared on sign-out. Synthetic mock mode is localhost/file only.

Source/observation dates, expired/draft focus, withheld/partial/stale/error states
are content, not decoration. Never turn unavailable data into an empty backlog.
No private browser cache, arbitrary external reader, raw HTML or fake live data.

This direction supersedes the former "extend the incumbent calm ledger" brief.
Backend safety and authorization contracts always take precedence over styling.
