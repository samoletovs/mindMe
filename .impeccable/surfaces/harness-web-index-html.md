# Hosted vault workspace

Mode: Operate / Read.

Scope: `harness\web\index.html`, `harness\web\tasks.css`,
`harness\web\tasks.js`, `harness\web\dashboard.js`.

One configured personal owner checks focus and existing task attention, then
opens a canonical daily finding or weekly digest. Original evidence is visible
in one interaction and its same-origin source in two. Feedback is not approval;
Make a task uses capture, exact preview, explicit approval and publication receipt.

The owner selected Dark kinetic studio for sign-in and the complete workspace:
graphite, warm ivory, narrow chartreuse accents, expressive native display type,
ruled working surfaces and purposeful fluid motion. The sign-in folding study is
original inline SVG, never a visualization of personal data. The same identity
continues through Today, Flow, Knowledge, Areas, Activity, Capture and Copilot.
There is a coherent light counterpart and EN/RU controls. No external assets.
The static composition must stand on its own under reduced motion.

Today pairs real loaded next moves with approved focus. Flow combines the
scrolling board/list with a task inspector; Knowledge makes original evidence one
interaction away. Fixed chrome stays still during work-area transitions. Finite
entrance and drawer motion replace ambient animation. Desktop header actions and
the phone safe-area action bar keep capture/voice/copilot reachable.

Task outcome and done condition lead the detail. A Capture / Detail / Estimate /
Plan / Execute / Resolve / Learn rail prepares source-bound AI work; chat accepts
English and Russian text/voice instructions. Applied changes show diffs and
receipt-bound Undo; approvals remain explicit wherever required by the server.
Never infer verified completion from a model reply. All conversation state is
in memory and cleared on sign-out. Synthetic mock mode is loopback-host only.

Source/observation dates, expired/draft focus, withheld/partial/stale/error states
are content, not decoration. Never turn unavailable data into an empty backlog.
No private browser cache, arbitrary external reader, raw HTML or fake live data.

Focus, keyboard return, partial-data truth, exact quotes and request recovery are
part of the composition, not optional polish. Source invalidation cannot be
removed to retain an editor, and a receipt refresh must not reopen a user-closed
task. No approval, backend, authentication or infrastructure scope is added.

This user-selected direction supersedes both the green ledger and violet
workspace. Public design and platform references are recorded in `DESIGN.md`.
Backend safety and authorization contracts always take precedence over styling.
